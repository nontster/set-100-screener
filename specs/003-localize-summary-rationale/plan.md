## Summary

Enable configurable target language output (`APP_LANGUAGE` in `.env` supporting ISO 639-1 / BCP 47 codes like `th` and `en`) for Executive Summaries and Classification Rationales generated by Gemini LLM synthesis. Combine LLM prompt parameterization with a deterministic Python regex post-processor to guarantee that recommendation decision terms (e.g. **REJECT**, **PASS**, **WATCHLIST**) are formatted in bold Markdown syntax (`**REJECT**`).
