# Contract Interface: Stock Classification Node & Export Format

**Feature Branch**: `002-dividend-growth-analysis`
**Date**: 2026-07-26

## 1. Node Signature Contract

```python
def stock_classifier_node(state: GraphState) -> Dict[str, Any]:
    """
    Executes quantitative classification, Mega Trend scoring, dividend safety evaluation,
    and LLM rationale synthesis.

    Input State Requirements:
    - ticker: str (e.g. "ADVANC.BK")
    - financial_data: Dict containing yfinance statement data
    - fraud_analysis: FraudAnalysisSchema output (from anti_fraud node)
    - news_sentiment: SentimentAnalysisSchema output (from news_sentiment node)

    Returns:
    - Dict with key 'classification_analysis' containing StockClassificationSchema dictionary.
    """
```

## 2. CSV & Excel Export Columns Contract

Export outputs (CSV / Excel generated by `src/batch.py` and `src/nodes/final_reporter.py`) MUST include the following columns:

| Column Header | Type | Example Value | Description |
|---------------|------|---------------|-------------|
| `Stock Category` | String | `DIVIDEND`, `GROWTH`, `HYBRID`, `NEUTRAL`, `REJECTED` | Primary classification |
| `Dividend Yield (%)` | Float | `5.4` | Current annual dividend yield |
| `Payout Safety` | String | `SAFE`, `CAUTION`, `UNSAFE`, `N/A` | Dividend safety assessment |
| `Growth CAGR (3Yr %)` | Float | `14.2` | Revenue 3-Year CAGR |
| `Mega Trend Tags` | String (Comma-separated) | `AI & Data Center Infrastructure` | Identified world trend alignments |
| `Classification Rationale` | Text | `High dividend yield of 5.4% backed by safe OCF coverage and strong AI Data Center telecom contract expansion.` | Factual summary narrative |

## 3. UI Dashboard Filter Contract (Streamlit)

Streamlit dashboard (`src/app.py`) contract:
- Filter Selectbox: `Category` (`All`, `DIVIDEND`, `GROWTH`, `HYBRID`, `NEUTRAL`, `REJECTED`)
- Multiselect Filter: `Mega Trends` (`AI & Data Center Infrastructure`, `EV & Renewable Energy`, `Healthcare & Aging Society`, `Digital Commerce & Smart Logistics`)
- Filter execution response time: `< 0.5 seconds` (client-side Pandas filtering).
